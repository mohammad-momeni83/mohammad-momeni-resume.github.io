📄 Personal Resume Website



A modern and responsive personal resume website built using React and Tailwind CSS.

This project showcases my skills, projects, and background through a clean UI and fast user experience.



🚀 Features



Responsive design for desktop and mobile



Modern UI built with Tailwind CSS



Component-based architecture using React



Fast performance powered by Vite



Simple and minimal portfolio layout



🛠 Tech Stack



React



Tailwind CSS



Vite



HTML / CSS / JavaScript



🎯 Purpose



The goal of this project is to present my personal portfolio and resume in an interactive and modern web format while practicing modern frontend development tools and UI design principles.
